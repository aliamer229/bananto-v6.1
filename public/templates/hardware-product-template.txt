# النصوص الطويلة: field<<EOF ... EOF
# العناصر المتكررة: feature.1= / feature.2= (بدون حد أقصى — .97 صالح مثل .1)
# العناصر المركبة: gallery.1.image= / gallery.1.title=
# المجموعات المتداخلة: spec_group.1.spec.2.value=
# القيم المنطقية: true أو false
# التواريخ: YYYY-MM-DD
# =========================================
# الأرقام المكتوبة في هذا القالب (.1 .2 .3) أمثلة فقط وليست حداً أقصى.
# أضف ما تحتاجه: feature.12= أو game_compatibility.40.game= تُقرأ جميعها.
# =========================================
# وسوم الحقول (تُقرأ آلياً ولا تُغيّرها):
#   @required     لا يكتمل المنتج بدونه
#   @recommended  يُستورد بدونه مع تنبيه في تقرير الجودة
#   @optional     لا تنبيه عند تركه فارغاً
#   @repeatable   يقبل عدداً غير محدود من العناصر
#   @conditional  يظهر فقط لنوع معيّن من المنتجات
#   @customer     قد يظهر للعميل في صفحة المنتج
#   @internal     داخلي — لا يُعرض للعميل إطلاقاً
# =========================================
# سياسة الحقول الفارغة:
# ابحث أولاً. لا تترك حقلاً قابلاً للبحث فارغاً بلا محاولة.
# إن لم تكن المعلومة منشورة: اكتب في الحقول النصية جملة دقيقة
# (مثال: "لم تنشر الشركة المصنّعة معلومات ضمان") — ولا تخترع قيمة أبداً.
# وللحقول الرقمية/المقيّدة اتركها فارغة وسجّل السبب في data_gap.N.
# الاستيراد لا يفشل بسبب حقل فارغ، لكن تقرير الجودة سيُظهر النقص.
