# Import sources — temporary

The Nintendo import templates for the August 2026 catalogue audit, extracted
from `all-nintendo-games-merged.zip`.

They live in the repository so the audit workflow can read them alongside
production D1 — matching a template against the live catalogue needs both in
one place, and a reproducible audit needs the inputs pinned rather than
re-uploaded.

These are inputs, not application code. Delete this directory once the import
is finished and the audit is closed.
